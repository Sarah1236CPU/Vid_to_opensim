# Vid_to_opensim
Script Python assurant la chaîne complète de traitement : extraction des points clés (RTMPose WholeBody) à partir de deux vidéos orthogonales (vue de face et vue de côté), reconstruction des coordonnées 3D, centrage sur le bassin, lissage par filtre  puis export au format .trc exploitable par OpenSim / Pose2Sim.
